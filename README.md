# Anirudh Iyengar's personal website

A small static academic website adapted from [Jon Barron's template](https://github.com/jonbarron/jonbarron.github.io). Content is based on the supplied résumé. No build step or JavaScript is required.

## Preview

Open `index.html` in your browser, or run `python -m http.server 8000` from this directory and visit http://localhost:8000.

## Customize

- Edit your bio, links, research, and projects in `index.html`.
- Replace `images/profile.svg` with a portrait and update the image path and alt text in `index.html`.
- Replace `data/Anirudh-Iyengar-Resume.pdf` when your résumé changes.
- Adjust layout and colors in `stylesheet.css`. The page uses the template's Lato typography and compact spacing, with responsive layout rules. Fonts are hosted locally in `fonts/`; their license is included there.
- Review dates and the incoming NeuroTechX role before publishing. The current text follows the supplied résumé.

The downloadable résumé is the original supplied PDF and includes its contact details. The page itself uses email, LinkedIn, and GitHub links.

## GitHub Pages

When ready, commit and push these files to the `main` branch of `asiyen02/asiyen02.github.io`. In the repository's Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**. The expected address is https://asiyen02.github.io/.

This setup does not publish automatically until the files are pushed and GitHub Pages is enabled. No custom domain is configured.
